# Legendary Wars Offline · 0.2.0

원작 이미지·음악과 새 Java 코드로 만든 개인용 Android 복원판입니다. 이번 버전은 사용자가 지정한 **전투 속도·AI·유닛 수치**를 우선 보정했습니다. 원작과 모든 동작이 동일한 완성판은 아닙니다.

APK는 `../dist/legendary-wars-offline.apk`입니다. Android 8.0 이상에서 사용합니다. 기존 0.1.0과 같은 개인 서명키/패키지이므로 업데이트 설치와 저장 이관을 지원합니다. 이전 APK는 `../dist/legendary-wars-offline-v0.1.0.apk`로 보존했습니다.

## 이번에 복원한 부분

- 원본에서 영웅 12종, 광부·적·특수 유닛을 포함한 69개 정의와 158개 외형/애니메이션 변형을 읽었습니다. 영웅은 Knighty, Elfy, Dwarfy, Faun, Rogue, Unicorn, Sprite, Golem, Centaur, Healer, Wizard, Phoenix입니다.
- 원본 기본 체력·공격·방어·속도·소환 비용·소환 쿨다운을 사용합니다. 이전 복원판의 임의 속도 배수와 쿨다운 단축을 실제 플레이 경로에서 제거했습니다.
- 원본 ARM 코드를 실행 없이 읽어 기본 애니메이션 15fps, 속도/공격/haste 보정 공식, 피해 난수와 치명타, 방어력 비율 계산을 확인해 반영했습니다. 원본이 지정한 24fps 같은 개별 설정도 유지합니다.
- 공격 애니메이션의 타격/발사 이벤트, Rogue의 두 발 발사, 원본 투사체 속도와 필살기 이동 보정을 연결했습니다. 직접 유닛 선택, 적 지정, 레인 이동, 화면 이동, 부대 명령을 추가했습니다.
- 원작 타이틀/목재 메뉴/지도/파란 천 버튼/영웅 선택창, 원작 폰트 2개와 음악 10개를 사용합니다. 원본 PNG/Ogg/TTF 바이트는 그대로 보존합니다.
- 7개 지역의 실제 스테이지 설정 73개, 원작 대사/튜토리얼·적 등장 시점·목표를 가져왔습니다. **설정 73개를 가져온 것이 73개 전체의 플레이 복원을 뜻하지는 않습니다.**
- 첫 튜토리얼, 채굴·소환 미션, 다섯 번째 엘프 구조 미션의 승리까지 순수 Java 자동 조작으로 확인했습니다. 구조 구역, 스크롤 속도, 반복 처치 카운터, 광부 구조, 보이지 않는 함정 이미지 문제를 수정했습니다.

## 조작

아군을 눌러 선택하고, 적을 누르면 그 적을 추적합니다. 빈 전장의 레인을 누르면 선택한 유닛이 이동합니다. 좌우 드래그로 전장을 볼 수 있습니다. 자동 스크롤 미션에서는 카메라가 원작 설정 속도로 이동합니다.

하단 아이콘은 소환, 상단 아이콘은 공격/대기/후퇴/그룹 선택, 우하단 Sun Star는 선택한 유닛의 필살기입니다. 원작 튜토리얼은 영어 원문을 표시하며 Continue로 넘깁니다. 광부 튜토리얼의 소환 버튼은 해당 안내 단계에서 활성화됩니다.

## 남은 차이

AI는 원본 설정의 attack/guard/hunt를 이용한 새 구현입니다. 모든 네이티브 AI 전환·피격 경직·충돌 반경·버프·특수 공격·방어 타입 상성을 완전히 포팅하지 않았습니다. 필살기 일부 효과와 스펠북/강화 경제도 원작 전체와 동일하지 않습니다.

후반의 별도 조작 모드·컨트롤러 오브젝트·탑 수비병 생성 등 미지원 동작이 있습니다. 따라서 후반 특정 미션은 진행이 막힐 수 있습니다. `reference/campaign-recovery.json`의 coverage에 읽지 못한 자원과 미지원 동작을 기록했습니다. 생존/보너스/몬스터 캠페인 등 별도 모드는 아직 복원하지 않았습니다. 와이드 화면 배치, 지도 일부 위치와 스크롤 배경 반복은 새 화면에 맞춘 보정입니다.

이 PC의 에뮬레이터는 가속 부재/소프트웨어 부팅 실패로 사용할 수 없어, **0.2.0의 Android 실기기 실행·터치·음악·성능은 아직 검증하지 못했습니다.** 브라우저의 메뉴 미리보기는 동일한 배치 데이터를 쓰는 정적 시각 확인이며 Android 캡처가 아닙니다.

## 보안 범위

원본 APK와 ARM 라이브러리는 실행·설치하지 않았습니다. 새 APK의 실행 코드는 직접 작성한 코드이며 원본 DEX/SO/JAR, 광고·분석 SDK, 네트워크 API, WebView, 동적 로딩, 셸 실행을 포함하지 않습니다. 요청 권한은 0개입니다.

원본 자료의 해시·압축 CRC·형식·좌표/테이블 경계를 검사했습니다. Ogg의 페이지 CRC와 Vorbis 식별자도 확인했습니다. 원본 plist 표현식은 평가하지 않고 허용된 조건과 명령만 새 코드가 처리합니다. Context7은 문서 확인에 사용했으며 악성코드 검사기로 사용하지 않았습니다. 다중 백신 무감염 인증이나 기기 감염 진단은 아닙니다.

## 재현

```powershell
node legendary-wars-reborn/tools/prepare-assets.mjs
./legendary-wars-reborn/test.ps1
./legendary-wars-reborn/build.ps1
```

프로젝트의 `.tools/jdk`, `.tools/android-sdk`와 테스트 전용 `.tools/combat-static/json-20240303.jar`를 사용합니다. 원본 추출/검증에는 보존된 `outputs/legendary-wars-analysis/samples/` APK/OBB가 필요하며 SHA-256이 달라지면 거부합니다. 준비된 assets로 빌드할 때는 원본이 필요하지 않습니다.

ARM 정적 분석 도구는 `.tools/combat-static` 안에만 준비했습니다. 공식 포터블 Python(PSF 서명 유효)과 Capstone을 쓰며 시스템 PATH/드라이버를 바꾸지 않았습니다. 이 분석 도구와 테스트 JSON 라이브러리는 APK에 포함하지 않습니다.

검증 상세는 `VERIFICATION.ko.md`, 네이티브 근거는 `reference/native-combat-findings.md`, 자료 출처/해시는 `asset-provenance.json`을 참고하세요. 개인 개발 서명키 `.local/legendary-development.keystore`는 보존하고 외부에 공개하지 마세요.
